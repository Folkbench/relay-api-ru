# Каталог API для русскоязычных разработчиков · Folkbench RU

**7 публичных сайтов, 6 редакционных групп** на 23 ноября 2026 (Asia/Shanghai). Владельцы всех групп независимо не аудировались. PlusVibe API и GetVibe показаны как связанная продуктовая группа, а не два независимых конкурента.

Это самостоятельный русскоязычный редакционный каталог в организации Folkbench. Мы не продаём API и не выдаём ключи. Наличие записи не означает рекомендацию, партнёрство, согласие поставщика на сотрудничество, тестирование или официальное включение в каталог сайта.

## Почему это не рейтинг

Сопоставимых собственных измерений нескольких поставщиков нет. Поэтому не публикуем места, SLA, проценты доступности, задержки, скорость или «победителя». Список по алфавиту. Поддержка протокола означает заявление в прочитанной документации, не проверку каждого метода или модели.

Публичные страницы цен прочитаны, но числовые ставки не перепечатываются: есть разные маршруты, приблизительные значения, «от», кэш и разные единицы. Перед оплатой откройте каталог поставщика. Наличие цены не означает выгодность, доступность карты или гарантию исполнения.

## Сайт и заявки

[Русский сайт Folkbench](https://ru.folkbench.com/) — отдельный продукт; здесь не объявляется его официальное открытие. [Заявка на сайт](https://ru.folkbench.com/submit/) проходит существующую ручную проверку. GitHub Issue — только редакционное предложение, не автоматическая публикация на сайте.

**База сайта остаётся единственным источником официального включения и актуальных измерений.** Этот репозиторий — независимый редакционный снимок публичных источников; синхронизация с базой не реализована. Изменение JSON не меняет сайт. Никакие ключи и частная переписка не принимаются через Issue.

## Поддержка материалов

Предложите исправление через [Issue](https://github.com/Folkbench/relay-api-ru/issues/new/choose) или PR. Укажите официальный источник и дату; см. [CONTRIBUTING.md](CONTRIBUTING.md).

Локальная проверка: `python3 scripts/check.py`. Пересборка сравнения: `python3 scripts/build.py`. Генерируемая страница и карточки должны соответствовать одному JSON. CI проверяет данные и воспроизводимость, но не актуализирует сведения и не вызывает API.

[Лицензирование оригинальных материалов и кода](LICENSE.md). Сведения проверены чтением открытых страниц, без регистрации, платных вызовов и обхода региональных правил.
