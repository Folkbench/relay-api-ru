# Как предложить изменение

1. Откройте Issue через шаблон или PR с одним конкретным исправлением.
2. Приложите официальный публичный источник, дату чтения и ограничения.
3. Не добавляйте секреты, чужую переписку, рекламные оценки и неподтверждённые гарантии.
4. Изменение проходит редакционную проверку. Не удаляйте неудобные ограничения.
5. При исправлении JSON обновите карточку и источники; не меняйте дату проверки без нового чтения источника.

**Редакционное включение ≠ официальная заявка ≠ одобрение ≠ партнёрство.**
Официальная заявка на сайт: https://ru.folkbench.com/submit/ . Ключи через GitHub не принимаются.
